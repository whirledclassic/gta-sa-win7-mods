# GroveLink troubleshooting

## Sanny: Incorrect expression 27@ = 22@

Pack **17** fixes that. Do not F7 the old file. Pull / extract v17, then double-click **COMPILE.bat**.

Open Sanny once first: Edit mode = **GTA San Andreas**.

## I press K and nothing appears

1. `[GTA]\CLEO\GroveLinkPhone.cs` must exist and be larger than a few hundred bytes. If it is missing, run **COMPILE.bat** or F7 `grovelink\GroveLinkPhone.txt` and copy the `.cs` into `CLEO`.
2. You need **CLEO 4.3 or 4.4**. `CLEO.asi` sits next to `gta_sa.exe`.
3. Run **CHECK.bat** as admin.
