# Companion switcher v8.0

Play as Sweet, Smoke, Ryder, Cesar, Grove FAM. **CJ stays** as a bot with a green radar blip.

## What v8 adds

- Green blip over the CJ body
- **Y** — CJ fights with you (foot: attack nearest threat, bike: drive-by). Aiming also pulls him into a fight. Story peds are left alone.
- **M** — CJ runs or rides to the red map waypoint (`0AB6`)
- Bike match — if you are on a Sanchez/BMX/PCJ, CJ gets the same model, not always a BMX
- **J** while CJ is riding puts you on his bike
- **T** while you are riding puts Sweet on a BMX
- Status line names fight / hold / shotgun / bike

## Keys

| Key | Action |
|-----|--------|
| **H** / **F6** | Become nearest companion (45 m, including riders) |
| **G** | Next |
| **J** | You are CJ (inherit his bike if he has one) |
| **U** | Hard reset |
| **N** | Send CJ away / call him back |
| **B** | Hold here / follow |
| **T** | Summon Sweet |
| **I** | Give CJ a bike |
| **Y** | Fight / stand down |
| **M** | Go to map marker |
| **L** | Status |

Compile `switcher/MissionSwitcher.txt` in Sanny (GTA San Andreas, F7) and copy `MissionSwitcher.cs` into `[GTA]\\CLEO\\`.
