# GroveLink Phone

CJ pulls the San Andreas cellphone and a handset HUD draws on the right of the screen with **contacts on-screen**.

Photos still go to your real phone on the same Wi-Fi.

## In GTA

- **K** pull out / put away the phone (cellphone animation)
- **Up / Down** move the menu
- **Enter** select
- **Backspace** back / close

### Home
CONTACTS, CAMERA, INBOX, CLOSE

### Contacts
Sweet, Smoke, Ryder, Cesar, OG Loc, Real Phone

### Camera
Enter snaps a photo. Keep `START_GROVELINK.bat` running so the real phone page gets the shot.

## Install (copy single files)

1. Compile `GroveLinkPhone.txt` in Sanny Builder → `[GTA SA]\CLEO\GroveLinkPhone.cs`
2. Copy `GroveLink.fxt` → `[GTA SA]\CLEO\GroveLink.fxt`
3. Copy `GroveLink/link.ini` → `[GTA SA]\CLEO\GroveLink\link.ini`
4. Run `bridge/START_GROVELINK.bat`
5. Open the printed URL on the real phone

If labels are missing, the `.fxt` is not in the CLEO folder. If there is no handset in CJ's hand, compile v5 (this file) and make sure you are on foot when you press K.
